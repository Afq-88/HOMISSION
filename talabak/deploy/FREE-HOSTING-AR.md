# النشر المجاني ١٠٠٪ — «طلبك معنا»

## لماذا ليست Render وأخواتها؟
النظام يخزّن طلبات عملاء حقيقية في قاعدة بيانات، فيحتاج **قرصًا دائمًا** و**عملًا بلا نوم**. الخطط المجانية في Render وKoyeb وRailway وFly وغيرها إما بلا قرص دائم (تضيع الطلبات عند كل إعادة تشغيل) أو تنام عند الخمول (يتعطل التنبيه اللحظي وأجهزة الجناح) أو تجريبية محدودة. لذلك لا أنصح بها لهذا النظام.

## الخياران المجانيان المناسبان
| | **أ) خادم Oracle Cloud Always Free** (الأفضل) | **ب) حاسوب في الشركة + Tailscale Funnel** |
|---|---|---|
| التكلفة | مجاني دائم (يُطلب بطاقة للتحقق فقط، لا يُخصم) | مجاني، بلا بطاقة |
| يعمل ٢٤ ساعة بلا اهتمام | نعم | فقط ما دام الحاسوب شغّالًا ومتصلًا |
| رابط HTTPS ثابت | نعم (`https://<عنوان>.sslip.io`) | نعم (`https://<اسم>.<شبكتك>.ts.net`) |
| الإعداد | ~٣٠ دقيقة | ~١٥ دقيقة |
| مخاطر | صعوبة الحصول على جهاز أحيانًا؛ قد تستعيد Oracle الأجهزة الخاملة جدًا | تعطل الحاسوب/الكهرباء/إنترنت المبنى = توقف النظام |

> **التوصية:** ابدأ بـ (ب) اليوم لتجرّب فورًا، وجهّز (أ) كمنصة المعرض الأساسية.
> **في الحالتين:** نزّل نسخة احتياطية يوميًا من «النسخ الاحتياطي ← تنزيل» واحفظها على حاسوب الشركة. هذه شبكة الأمان الحقيقية.

## أ) Oracle Cloud Always Free
١. أنشئ حسابًا في cloud.oracle.com. اختر **Home Region قريبة**: Dubai أو Abu Dhabi أو Jeddah أو Frankfurt (لا تُغيَّر لاحقًا، وموارد Always Free في المنطقة الأم فقط).
٢. **Compute ← Create instance**: الصورة **Ubuntu 24.04**، الشكل **VM.Standard.E2.1.Micro** (AMD، ضمن Always Free). أنشئ مفتاح SSH واحفظه.
٣. **الشبكة:** في الـ VCN ← Security List ← أضف **Ingress Rules** للمنفذين **TCP 80 و443** من `0.0.0.0/0`. (يلزم ذلك إضافة إلى جدار الخادم الذي يفتحه السكربت.)
٤. اتصل بالخادم: `ssh ubuntu@<العنوان>` ثم:
```bash
sudo apt-get update && sudo apt-get install -y git
git clone -b claude/kptc-request-app-3t4trj https://github.com/Afq-88/HOMISSION.git
sudo bash HOMISSION/talabak/deploy/vm-setup.sh
```
(إن كان المستودع خاصًا فاستعمل رمز وصول شخصي من GitHub بدل كلمة المرور.)
٥. ينتهي السكربت بطباعة **الرابط** و**كلمة مرور المدير المؤقتة**. افتح `https://…/staff` وغيّر كلمة المرور.
٦. ثبّت عنوان IP: في Oracle ← Networking ← **Reserved Public IP** مجاني وأرفقه بالجهاز، حتى لا يتغير الرابط (والـQR المطبوع).
٧. تحديث التطبيق لاحقًا: `cd HOMISSION && git pull && sudo bash talabak/deploy/vm-setup.sh` (لا يمس البيانات ولا كلمات المرور).

**تنبيه Oracle:** تحتفظ لنفسها بحق استعادة الأجهزة الخاملة جدًا. نشاط النظام أثناء المعرض (نبض الأجهزة والتنبيهات) يقلل ذلك، لكن لا ضمان. التخفيف: ترقية الحساب إلى Pay-As-You-Go (لا يُخصم شيء داخل حدود Always Free) + النسخ الاحتياطي اليومي.
**بديل مماثل:** Google Cloud e2-micro (Always Free في مناطق أمريكا فقط؛ يحتاج بطاقة أيضًا). السكربت نفسه يعمل عليه.

## ب) حاسوب الشركة + Tailscale Funnel (بلا بطاقة)
١. على حاسوب Windows يبقى شغّالًا ومتصلًا طوال المعرض (وأوقف السكون: Power → Never): ثبّت **Node.js 22+** من nodejs.org.
٢. انسخ مجلد `talabak` إلى الحاسوب (أو حمّل المستودع كملف ZIP من GitHub). شغّل `deploy\windows\start-talabak.bat` (نقرة مزدوجة). يعمل على `http://localhost:3000` ويعيد تشغيل نفسه عند التوقف.
   أنشئ المدير أول مرة: افتح Terminal في المجلد ونفّذ `npm run create-admin` (تظهر كلمة مرور مؤقتة).
٣. ثبّت **Tailscale** (tailscale.com، الخطة الشخصية مجانية) وسجّل الدخول. من لوحة الإدارة admin console فعّل **MagicDNS** و**HTTPS Certificates**، وفعّل **Funnel** لهذا الجهاز.
٤. في Terminal بصلاحية مدير: `tailscale funnel --bg 3000`. سيعرض رابطًا ثابتًا مثل `https://pc-name.tailxxxx.ts.net`. هذا هو رابط الزوار والـQR.
٥. في `start-talabak.bat` أزل `rem` من سطر `COOKIE_SECURE=1` (ثم أعد التشغيل) وادخل دائمًا عبر رابط HTTPS.
٦. الاستضافة على Funnel قد لا تمرّر عنوان الزائر الحقيقي؛ إن لاحظت رسالة «عدد المحاولات كبير» عند كثرة الزوار، ارفع «حد الإرسال لكل جهاز / ١٠ دقائق» من الإعدادات إلى ٦٠٠.
**قيود:** Funnel يخضع لحدود نطاق ترددي غير معلنة (كافية لنموذج نصي)، وقد تحجبه سياسة شبكة الشركة. جرّب من جوالك على بيانات الهاتف قبل الاعتماد عليه.

## بعد النشر (الحالتين)
1. «الإعدادات ← رابط النشر العام» = رابطك. ثم «ملصق QR» و«الروابط» وسجّل طلبًا تجريبيًا بجوال حقيقي قبل الطباعة.
2. على الآيباد: افتح `/staff` في Safari ← «إضافة إلى الشاشة الرئيسية» ← فعّل 🔔.
3. أجهزة الجناح: افتح `/kiosk` وأضفه للشاشة الرئيسية (ملء الشاشة).
4. نسخة احتياطية يومية: «النسخ الاحتياطي ← تنزيل».

## ما لم يُختبر هنا
سكربت `vm-setup.sh` وملف `.bat` ومسار Tailscale **لم أنفّذها على خادم/حاسوب حقيقي** (بيئتي لا تملك حساباتكم ولا تصل إلى هذه المنصات). فحصتُ صياغة السكربت وجرّبتُ أجزاءه الأساسية (فحص/إنشاء المدير، الربط المحلي خلف الوسيط، الكوكي الآمن)، وسيُكتشف أي خلل في بيئتكم عند أول تشغيل — أرسل لي مخرجات الخطأ وأصلحه.
