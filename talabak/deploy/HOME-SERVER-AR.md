# خادم منزلي/مكتبي (ماك بوك برو ٢٠١٠) — دليل مخصص

## الخلاصة
جهازك يصلح كخادم **بعد تثبيت Ubuntu Server عليه** (وليس macOS). النظام خفيف جدًا: ذاكرة ٤GB وقرص ٥١٢GB أكثر من كافيين. لا تشتري شيئًا.

> **قبل أي شيء، أخبرني بنموذج الجهاز بالضبط** (قائمة Apple ← «حول هذا الـ Mac»): هل هو **١٥″/١٧″ (Core i5/i7)** أم **١٣″ (Core 2 Duo)**؟
> الأول يعمل غالبًا بلا مشاكل. الثاني بلا تعليمات SSE4.2، وقد لا يشغّل Node 22 (المطلوب لقاعدة البيانات المدمجة). السكربت يفحص ذلك ويتوقف برسالة واضحة، ولدي حل بديل إن لزم.

## لماذا Ubuntu وليس macOS؟
أحدث macOS يدعمه جهازك قديم جدًا، وNode 22 يتطلب macOS 11 فأحدث. Ubuntu Server 24.04 LTS (أو 22.04) يعمل على أجهزة Intel Mac ويتلقى تحديثات أمان لسنوات.

## الشبكة (راوتر Ooredoo 5G)
«IP ثابت» عند Ooredoo 5G المنزلي غالبًا يعني **CGNAT** (عنوان مشترك لا يستقبل اتصالات من الخارج). تحقق: قارن عنوان WAN في صفحة الراوتر مع نتيجة `curl ifconfig.me` من الجهاز؛ إن اختلفا (أو بدأ بـ `100.64.` – `100.127.`) فلا يمكن فتح منافذ.
**الحل الموصى به في الحالتين: Tailscale Funnel** — مجاني، يعمل بلا فتح أي منفذ في راوتر منزلك (فلا تتعرض شبكتك المنزلية)، ويعطيك رابط HTTPS ثابتًا `https://<جهازك>.<شبكتك>.ts.net`.
(وضع Caddy مع IP عام ممكن فقط إن ثبت أن العنوان عام وأن Ooredoo تسمح بتحويل المنافذ، وهو يعرّض راوتر المنزل؛ لا أنصح به.)

## التثبيت (خطوة بخطوة)
**١) Ubuntu على الماك** (يحتاج فلاشة USB وكابل شبكة؛ الواي فاي يحتاج تعريفًا لا نحتاجه):
- حمّل Ubuntu Server 24.04 LTS، وأنشئ فلاشة إقلاع بـ balenaEtcher.
- أطفئ الماك، وصّل كابل الشبكة، شغّله مع الضغط المستمر على **Option (⌥)**، اختر «EFI Boot».
- في المثبّت: اختر استخدام كامل القرص، فعّل **OpenSSH server**، وأنشئ مستخدمًا واختر كلمة مرور قوية. (تشفير القرص LUKS اختياري: أقوى لكنه يتطلب إدخال العبارة بالكيبورد بعد أي انقطاع كهرباء.)
- إن واجهت مشكلة إقلاع: ابحث عن «Ubuntu MacBookPro6,2» (حسب نموذجك) أو جرّب Ubuntu 22.04.

**٢) نسخ المشروع وتثبيته:**
```bash
sudo apt-get update && sudo apt-get install -y git
git clone -b claude/kptc-request-app-3t4trj https://github.com/Afq-88/HOMISSION.git
sudo bash HOMISSION/talabak/deploy/vm-setup.sh --mode=tailscale --laptop
```
يطبع السكربت كلمة مرور المدير المؤقتة وسرّين **(احفظهما خارج الجهاز)**.

**٣) إظهاره على الإنترنت:** نفّذ الخطوات التي يطبعها السكربت في آخره: `sudo tailscale up` ← فعّل MagicDNS وHTTPS من لوحة Tailscale ← فعّل Funnel ← `sudo tailscale funnel --bg 3000`.

**٤) قفل لوحة الموظفين عن الإنترنت العام (اختياري وقوي جدًا):** أضف `--funnel-public-only` عند التثبيت (أو `Environment=FUNNEL_PUBLIC_ONLY=1` في ملف الخدمة). عندها **لا يصل أحد من الإنترنت إلى `/staff` ولا واجهات الإدارة** — يرى الزوار النموذج فقط. تدخل أنت لوحة الموظفين من آيبادك/جوالك بعد تثبيت تطبيق **Tailscale** عليهما (مجاني) وتسجيل الدخول بنفس حسابك، ثم تفتح نفس الرابط.
القيد: خطة Tailscale المجانية تتسع لـ ٣ مستخدمين؛ إن كان موظفوك أكثر فاتركه معطّلًا (الحماية تبقى: مصادقة ثنائية + حدود محاولات).
> لم أتمكن من اختبار هذا الوضع على Tailscale حقيقي: يعتمد على ترويسة موثّقة تضيفها Tailscale لطلبات Funnel، وجرّبته آليًا بمحاكاتها.

**٥) النسخ الاحتياطي خارج الجهاز (مجاني):** النسخ مشفّرة، فيمكن رفعها بأمان إلى Google Drive/OneDrive/Mega:
```bash
sudo apt-get install -y rclone
sudo rclone config                       # أنشئ ريموتًا اسمه gdrive (على جهاز بلا متصفح: rclone authorize "drive" من جهاز آخر)
sudo bash HOMISSION/talabak/deploy/offsite-backup.sh gdrive
```
يرفع كل ٦ ساعات. بقي أن تحفظ `BACKUP_PASSPHRASE` خارج الجهاز؛ بدونها لا تُفتح النسخ.

## الكهرباء والحرارة (أهم نقطة ضعف عندك)
- **لا يوجد UPS:** بطارية الماك تقوم مقامه. بطارية ٢٠١٠ غالبًا ضعيفة (دقائق إلى ساعة). السكربت يضبط الإيقاف الآمن عند ١٠٪ لحماية البيانات.
- ⚠ **افحص البطارية:** إن رأيت انتفاخًا (لوحة اللمس مرتفعة أو الغطاء السفلي مفتوح) فتوقف عن استخدامها فورًا لخطر الحريق، وأخرجها.
- **انقطاع أطول من البطارية = توقف الخادم** حتى تضغط زر التشغيل (لا تتوفر إعادة التشغيل التلقائية في اللابتوبات). لذلك: راقب بـ UptimeRobot (مجاني، يرسل لك تنبيهًا)، واحتفظ بالنموذج الورقي، وحمّل نسخة يوميًا.
- **الحرارة:** ضع الجهاز على سطح صلب مفتوح الهواء، وليس على سجادة أو سرير. السكربت يثبّت `thermald` و`mbpfan` للتحكم بالمراوح؛ راقب بـ `sensors`. غطاء مغلق مقبول لكنه أسخن.
- لا تغلق الجهاز من الزر؛ استخدم `sudo shutdown now` ليُغلق التطبيق نظيفًا.

## أمان المنزل
غيّر كلمة مرور إدارة الراوتر، عطّل UPnP، ولا تفتح أي منفذ (Funnel لا يحتاج). الجدار على الجهاز يمنع كل شيء عدا Tailscale وSSH من شبكتك المحلية. ضع الجهاز في مكان مقفل بعيدًا عن غير المخوّلين.

## وماذا عن الآن؟ (المعرض بدأ اليوم)
**لا تعلّق المعرض على ترقية الجهاز.** اليوم:
- ابدأ بالنموذج الورقي، أو شغّل المشروع على أي حاسوب Windows/Mac حديث بدلًا من الماك القديم (`deploy/windows/start-talabak.bat` + Tailscale Funnel).
- عندما يجهز الماك، انقل كل شيء: نزّل نسخة احتياطية → ثبّت على الماك → `sudo talabak-admin restore <الملف>` (للنسخة المشفّرة ضع `BACKUP_PASSPHRASE` نفسها وأعد تفعيل 2FA إن اختلف `APP_SECRET`).

## عملي معك على الجهاز
حاليًا لا يظهر لي أي جهاز متصل (فحصت). تطبيق Claude لسطح المكتب غير متوفر على Linux، لذا بعد تثبيت Ubuntu لن أتصل به تلقائيًا. الخيارات: (أ) ثبّت **Claude Code** على الخادم (`npm install -g @anthropic-ai/claude-code`) وتحدث معه هناك داخل مجلد المشروع؛ (ب) نفّذ أنت الأوامر وألصق لي المخرجات لأصحح. وإن أبقيت macOS على جهاز آخر حديث فيمكنني الاتصال به عبر تطبيق Claude.
