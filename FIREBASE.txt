نشر الموقع مجاناً على Firebase Hosting — دومين مجاني ينتهي بـ web.app
=====================================================================

ما الذي ستحصل عليه (كله مجاني 100% ضمن خطة Spark، بلا بطاقة ائتمان):
  - دومين:  https://اسم-مشروعك.web.app   (وأيضاً  اسم-مشروعك.firebaseapp.com)
  - شهادة أمان SSL تلقائية.
  - استضافة: 10GB تخزين و 360MB نقل يومياً.
  - الخريطة OpenStreetMap + Leaflet (مرفقة)، والخطوط من Google Fonts، والترجمة من
    مترجم Google للمواقع: كلها بلا مفتاح ولا رسوم.

ملاحظة عن الاسم:
  لا يمكن أن يكون الدومين google.web.app لأن الاسم محجوز لأول من سجّله. اسم الدومين
  هو «معرّف المشروع» (Project ID)، ويجب أن يكون فريداً في العالم. اختر شيئاً مثل:
  kptc-kw أو kptc-official أو kptc-kuwait. إن كان محجوزاً يقترح لك Firebase بديلاً
  (مثل kptc-kw-7a3f).

لا أستطيع أنا الدخول إلى حسابك في Google ولا إنشاء المشروع نيابة عنك، لأن ذلك يتطلب
تسجيل دخولك أنت. لكن الخطوات أدناه مرتبة بحيث تنهيها في نحو 15 دقيقة.

---------------------------------------------------------------------
الجزء 1 — إنشاء المشروع (يفتح لك Firebase و Google Cloud معاً)
---------------------------------------------------------------------
  1. افتح  https://console.firebase.google.com  وسجّل الدخول بحساب Google.
  2. اضغط «Create a project» (إنشاء مشروع).
  3. اكتب اسماً (مثل KPTC) ثم اضغط «Edit» بجانب الاسم المقترح لتضع معرّف المشروع
     الذي اخترته (مثل kptc-kw). هذا المعرّف هو ما سيظهر في الدومين.
  4. قد يسألك عن Google Analytics: يمكنك إيقافه (Disable) لتبسيط الأمر.
  5. اضغط «Create project» وانتظر دقيقة.
  ملاحظة: إنشاء مشروع Firebase ينشئ مشروع Google Cloud بالاسم نفسه تلقائياً. ولا حاجة
  لفتح حساب Google Cloud منفصل ولا لإضافة بطاقة.

---------------------------------------------------------------------
الجزء 2 — رفع الموقع (اختر طريقة واحدة)
---------------------------------------------------------------------

الطريقة أ (الأسهل — من المتصفح بلا تثبيت أي شيء): Google Cloud Shell
  1. افتح  https://shell.cloud.google.com  بالحساب نفسه. تظهر لك شاشة سوداء (طرفية)
     جاهزة وفيها Node.js.
  2. اضغط على قائمة النقاط الثلاث ⋮ في أعلى الطرفية ← Upload ← اختر ملف
     KPTC_Website_vXX.zip (آخر نسخة أرسلتها لك).
  3. اكتب الأوامر التالية سطراً سطراً (استبدل kptc-kw بمعرّف مشروعك):
        mkdir site && cd site
        unzip ../KPTC_Website_*.zip
        npx firebase-tools login --no-localhost
        npx firebase-tools use kptc-kw
        npx firebase-tools deploy --only hosting
     - في أمر login ستظهر لك رابط افتحه في المتصفح، اضغط «Allow»، وانسخ الرمز الذي
       يظهر وألصقه في الطرفية.
     - إن سألك «Y/N» أجب Y.
  4. في آخر الأمر يطبع لك: Hosting URL: https://kptc-kw.web.app  ← هذا هو موقعك.

الطريقة ب (من جهازك): تحتاج تثبيت Node.js من https://nodejs.org
  1. فك ضغط ملف الموقع وافتح الطرفية داخل المجلد.
  2. نفّذ:
        npm install -g firebase-tools
        firebase login
        firebase use kptc-kw
        firebase deploy --only hosting
  3. افتح  https://kptc-kw.web.app

عند أي تحديث لاحق: ارفع ملف ZIP الجديد بالطريقة نفسها ونفّذ أمر deploy مرة أخرى.
ملف firebase.json مرفق وجاهز: يرفع index.html ومجلدي pages و assets فقط.

بديل بلا أوامر إطلاقاً: Netlify. اسحب ملف ZIP إلى https://app.netlify.com/drop
فيعطيك رابطاً مجانياً (ينتهي بـ netlify.app). لكنه ليس web.app.

أخطاء شائعة:
  - «Project ID already exists/taken»: غيّر المعرّف قليلاً (أضف رقماً أو -kw).
  - «Permission denied»: تأكد أنك سجّلت الدخول بالحساب الذي أنشأ المشروع.
  - الدومين لا يفتح فوراً: انتظر دقيقتين ثم أعد التحميل (Ctrl+Shift+R).

---------------------------------------------------------------------
الجزء 3 — قاعدة البيانات Firestore (لتصير الحسابات والإعدادات مشتركة بين الجميع)
---------------------------------------------------------------------
  هذا الجزء اختياري الآن. الموقع يعمل بدونه، لكن البيانات (الحسابات، المحافظ، الحجوزات،
  التعاميم، الصلاحيات، تعديلات النصوص) تُحفظ حالياً في متصفح كل زائر، فلا يراها غيره.

  1. في لوحة Firebase: Build ← Firestore Database ← Create database.
     - اختر الموقع الأقرب (مثل eur3 أو me-central2 إن ظهر)، وهو لا يتغير بعد ذلك.
     - اختر «Start in production mode» ثم Create. (لا تحتاج بطاقة.)
  2. Build ← Authentication ← Get started ← فعّل Email/Password.
  3. Project settings (أيقونة الترس) ← General ← Your apps ← أيقونة الويب </> ←
     سمِّ التطبيق واضغط Register، ثم انسخ الكائن firebaseConfig.
     ثم أرسله لي هنا في المحادثة. هذه القيم ليست أسراراً (تظهر لكل زائر للموقع)،
     والحماية الحقيقية تأتي من قواعد الأمان Security Rules التي سأكتبها لك.
  4. بعد وصول firebaseConfig أربط طبقة البيانات src/store.js بـ Firestore. وتجربة الربط
     نفسها تحتاج مشروعك، فسأضع لك ما يلزم وتتحقق أنت منه على مشروعك.

  حدود الخطة المجانية Spark: 50 ألف قراءة و 20 ألف كتابة يومياً و 1GB تخزين.
  تكفي موقعاً بحجم موقع شركة النقل في بدايته بكل أريحية.

---------------------------------------------------------------------
ما يبقى مجانياً وما قد يطلب بطاقة
---------------------------------------------------------------------
  مجاني بلا بطاقة: Hosting، Firestore (ضمن الحصة)، Authentication (Email وGoogle)،
                    Cloud Shell، ومشروع Google Cloud نفسه.
  يتطلب Blaze (بطاقة، مع حصة مجانية شهرية): Cloud Functions، ومنها الدفع الحقيقي عبر
                    كي نت. وهي غير لازمة لتشغيل الموقع بصيغته الحالية.
  الدفع في الموقع وشحن المحفظة تجريبيان ولا يُخصم فيهما أي مبلغ.

قواعد الأمان جاهزة في firestore.rules (انشرها بـ: firebase deploy --only firestore:rules).
خطوات التهيئة الأولى للمسؤول وMFA وApp Check: docs/SECURITY-ARCHITECTURE.md الفقرة 7.

تنبيهات أمنية قبل فتح الموقع للعموم:
  - الحسابات التجريبية للموظفين (كلمة المرور 12345678) يجب حذفها أو تغييرها.
  - مركز إدارة الموقع يجب أن يُحمى بقواعد Firestore، لا بإخفاء الصفحة فقط.
  - تعبئة المحفظة والخصم منها يجب أن يتما من الخادم بعد تأكيد بوابة الدفع.
