نشر الموقع مجاناً على Firebase Hosting (دومين مجاني ينتهي بـ web.app)
=====================================================================

كل ما في هذا الملف مجاني 100% ضمن خطة Spark (بدون بطاقة ائتمان):
  - الاستضافة: 10GB تخزين و 360MB نقل يومياً، مع شهادة SSL.
  - الدومين: https://اسم-المشروع.web.app و https://اسم-المشروع.firebaseapp.com
  - الخريطة: OpenStreetMap + مكتبة Leaflet (مرفقة داخل assets)، بلا مفتاح ولا رسوم.
  - الخطوط: Google Fonts.

الخطوات (مرة واحدة، نحو 10 دقائق):
  1. افتح https://console.firebase.google.com بحساب Google وأنشئ مشروعاً
     (مثلاً kptc-kw). إنشاء المشروع يفتح معه حساب Google Cloud تلقائياً.
     اسم المشروع هو ما يظهر في الدومين: kptc-kw.web.app
  2. على جهازك (يلزم Node.js):
        npm install -g firebase-tools
        firebase login
  3. فك ملف الموقع، وادخل المجلد من الطرفية ثم:
        firebase use --add        (اختر مشروعك)
        firebase deploy --only hosting
  4. افتح https://اسم-المشروع.web.app

ملف firebase.json مرفق وجاهز: يرفع index.html ومجلدي pages و assets فقط.

قاعدة البيانات (Firestore) — المرحلة التالية:
  الموقع يحفظ الآن الحسابات والمحافظ والحجوزات والأخبار والمناقصات والوظائف داخل
  متصفح الزائر (localStorage) عبر طبقة واحدة: src/store.js. لذلك ما يفعله زائر لا
  يراه زائر آخر، وإخفاء صفحة من مركز الإدارة يسري على المتصفح نفسه فقط.
  لجعلها مشتركة بين كل الزوار تُربط الطبقة نفسها بـ Firestore و Firebase Auth:
      users/{uid}            بيانات العميل
      wallets/{uid}          الرصيد والحالة، وحركاتها في wallets/{uid}/tx
      bookings/{id}          الحجوزات والطلبات
      news, tenders, bids, jobs, applications
      settings/pages         ظهور الصفحات وشريط التنبيه
  من لوحة Firebase: Build ← Firestore Database ← Create database، و
  Build ← Authentication ← Sign-in method ← Phone أو Email.
  ثم Project settings ← Your apps ← Web app وانسخ كائن firebaseConfig.
  خطة Spark تكفي: 50 ألف قراءة و 20 ألف كتابة يومياً و 1GB تخزين.

تنبيه أمني قبل الربط الحقيقي:
  - تعبئة المحفظة والخصم يجب أن تُنفّذ من الخادم (Cloud Functions) بعد تأكيد
    بوابة الدفع، وليس من المتصفح. Cloud Functions تتطلب خطة Blaze (دفع حسب
    الاستخدام) ولها حصة مجانية شهرية.
  - مركز إدارة الموقع ولوحة التحكم يجب حمايتهما بتسجيل دخول وصلاحيات
    (Firestore Security Rules) قبل النشر للعموم.
