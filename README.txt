KPTC — المنظومة الرقمية المتكاملة
نسخة جاهزة للرفع على الدومين أو Netlify — الإصدار 3 («لغة المحطّة»)
=====================================================================

محتوى المجلد للرفع:
  index.html      ← بوابة العرض (خريطة المنظومة)
  pages/          ← 22 صفحة، كل صفحة ملف واحد
  assets/         ← صور الحافلات الرسمية ومكتبة الخريطة
  firebase.json   ← إعداد Firebase Hosting (اقرأ FIREBASE.txt)

الرفع المجاني:
  - Firebase (دومين web.app): اتبع FIREBASE.txt.
  - Netlify: اسحب ملف ZIP إلى Deploy manually.
  - أي استضافة عادية: ارفع index.html و pages و assets كما هي.

جديد الإصدار 4:
  - «حسابي»: تسجيل ودخول، حجوزات وطلبات العميل، ومحفظة تُشحن ويُدفع منها.
    أي حجز من صفحات الخدمات يُحفظ في الحساب تلقائياً.
  - «مركز إدارة الموقع»: إظهار وإخفاء الصفحات، شريط تنبيه عام، إدارة الأخبار
    والمناقصات والوظائف وطلبات التوظيف، المحافظ (تعبئة، خصم، استرجاع، إيقاف)،
    وكل الحجوزات مع تغيير حالتها، وسجل نشاط.
  - صفحات جديدة: المركز الإعلامي بأقسامه، المناقصات، الوظائف والتقديم.
  - خريطة حقيقية في صفحة الخطوط (OpenStreetMap + Leaflet، مجاناً وبلا مفتاح).
  - معاينة الإعلان على صورة حافلة K-Bus الرسمية، ومعرض صور حقيقية لحافلات VIP.
  - الأرقام تُكتب وتُعرض دائماً 0-9 مهما كانت لغة لوحة المفاتيح.
  - حُذفت صفحات «منظور المستخدمين» وحلّت محلها صفحة «حسابي».

مهم: البيانات (الحسابات، المحافظ، الحجوزات، ظهور الصفحات) محفوظة حالياً في متصفح
الزائر نفسه. لتصبح مشتركة بين كل الزوار تُربط بـ Firestore (الخطوات في FIREBASE.txt).
الدفع وشحن المحفظة تجريبيان ولا يُخصم فيهما أي مبلغ.

روابط مباشرة لأي صفحة (مثال):
  https://الدومين/#/exec         العرض التنفيذي
  https://الدومين/#/dashboard    لوحة التحكم
  https://الدومين/#/realestate   إدارة الأصول العقارية

الهوية البصرية الجديدة — «لغة المحطّة»:
  - ألوان KPTC الرسمية: النيلي ‎#2E2C78‎ والأصفر ‎#FFC93C‎، على خلفية «ورق التذاكر».
  - الخطوط: Noto Kufi Arabic للعناوين، IBM Plex Sans Arabic للنصوص (Google Fonts،
    ومع انقطاع الإنترنت تعمل الصفحات بخطوط النظام).
  - عناصر مستوحاة من النقل العام: خريطة الخطوط، لافتة المحطة، لوحة LED، التذكرة،
    شريط المحافظات الست في التذييل، وشعار الدبوس الرسمي بدل حرف «K».
  - أيقونات خطية موحّدة بدل الرموز التعبيرية (Emoji).

ملاحظات للجهة المنفذة:
  - جميع الصفحات HTML/CSS/JavaScript فقط — لا تحتاج قاعدة بيانات أو خادم خاص.
  - البيانات المعروضة توضيحية ومخزنة داخل كل صفحة، وتُفقد التعديلات عند إعادة التحميل.
  - الربط الفعلي (قاعدة بيانات، بوابة KNET، تسجيل دخول، ذكاء اصطناعي حقيقي)
    يتطلب تطويراً من الجهة المنفذة.
  - لوحة التحكم يجب حمايتها بكلمة مرور قبل النشر العام.
  - عند فتح أي صفحة منفردة، روابطها الداخلية تعيد التوجيه عبر البوابة تلقائياً.

للمطوّرين (تعديل التصميم):
  src/core.css, src/core.js   ← نظام التصميم المشترك (الألوان، الخطوط، الرأس والتذييل، الأيقونات)
  src/pages/<page>.css        ← طبقة التصميم الخاصة بكل صفحة
  src/decorate.json           ← أصناف التصميم المضافة إلى عناصر الصفحات (إضافة فقط)
  src/store.js                ← طبقة البيانات المشتركة (تُستبدل بـ Firestore)
  src/site/*.html             ← مصادر الصفحات الجديدة، يبنيها tools/site_pages.py
  python3 tools/build.py      ← يحقن التعديلات في كل الصفحات بعد أي تغيير في src
  python3 tools/feature_check.py <النسخة_الأصلية> .   ← يتأكد أنه لم تُفقد أي ميزة
  node tools/smoke.js .       ← يضغط كل زر في كل صفحة ويرصد أخطاء JavaScript
